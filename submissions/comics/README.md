## Adding future comics

Create a folder under `submissions/comics/<project-slug>/` with a `README.md` listing its materials. Add a link from this index to make the project browsable. Follow the root [contributor guidelines](../../CONTRIBUTING.md) and [submission rules](../../SUBMISSION-RULES.md).

**Reminder:** Being indexed for discovery does not mean a submission has been accepted into the sandbox or made canon.
